## طبيعة النتائج
فُحصت الملفات الـ4,309 آليًا، مع خرائط نطاقات متجاورة وفهرس مؤشرات لكل فصل. القراءة النقدية المتصلة تركز على الفصول 1–20 و620–629 من «مناعة الألم»، والفصول 1–10 لكل رواية أخرى، مع فصول استدلالية لاحقة. **لا ندعي قراءة نقدية يدوية كاملة لجميع الفصول.**

## محاور الدراسة
- اختبار القواعد مقابل الافتراضات الاجتماعية وفعل البطل تحت نقص المعلومات.
- الحوار الذي ينشئ صراعًا، لا يكرر تفسيره.
- الزمن والرفقة وبناء التعاطف عبر التفاصيل العادية.
- تحول ساحات الصراع مع إبقاء تبعات القرارات القديمة.
- مقاومة الكتابة المعلبة: تباين أصوات الشخصيات، والحذف الذكي للشرح، والقرائن العادلة.
