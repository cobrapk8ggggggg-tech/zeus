# الرسم السببي الأولي

المعرفات والأدلة في `../data/causal_edges.jsonl`. استرجاع التوابع بالأداة `tools/query.py dependents EVENT_ID`. الأداة تستبعد التتابع الزمني، وتتجنب الدورات باستخدام UNION، ولا تساوي العامل المساعد بالشرط اللازم. لا تقدّر احتمالات عددية بلا أساس.

مثال: نتيجة الأكبر → صدمة الأصغر → [عامل مساعد] سقوطه → [شرط هذه الصورة] مساعدته. نتيجة A للأصغر → تنافس الرعاية. مساعدة النهر تسبق A لكنها ليست سببًا مثبتًا للموهبة.
