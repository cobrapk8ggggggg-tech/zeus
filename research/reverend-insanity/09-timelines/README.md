# الخطوط الزمنية

السجل الآلي في `../data/events.jsonl` وجدول `events`. `previous-life` للحصار السابق، و`main` لما بعد العودة. التاريخ القديم `ancient` لم يُملأ كوقائع مؤكدة؛ أسطورة رين زو منفصلة، والهجرة ترد كذاكرة (4.txt:35–39). لا نسد فجوات الخمسمائة عام.

تاريخ البداية النسبي: ليلة قبل الإيقاظ (1–2)، ثم صباح المراسم (3–6). لا تاريخ مطلق مخترع. العودة المراجعة واحدة فقط؛ العودات اللاحقة غير مدروسة. حقول الموارد المنتقلة والتوابع والنتائج المفصلة تتطلب توسعة السجل مع الدفعة التالية.
