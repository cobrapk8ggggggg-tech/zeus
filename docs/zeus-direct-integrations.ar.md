# الاتصالات المباشرة والمهارات الافتراضية

- الإضافات في إعدادات Zeus تعرض GitHub وRailway وVercel حتى دون خادم مشاريع.
- الاتصالات المباشرة مسجلة بأسماء `zeus-direct-*` في MCPStore الأصلي وتستخدم عميل MCP المحلي وبيئة الجهاز. لا تمر برابط `/mcp` لخادم Zeus. يبقى الخادم البعيد الذي توفره GitHub أو Vercel أو Railway ضرورياً لخدماتها نفسها.
- تتوفر المصادقة برمز الوصول، وإعدادات OAuth الأصلية، واكتشاف OAuth وتسجيل العميل ديناميكياً عندما تدعم الخدمة ذلك. عدم دعم التسجيل الديناميكي يظهر خطأ واضحاً ويتيح إعداد العميل الأصلي؛ لا يُختلق Client ID.
- حفظ الاتصال ليس دليلاً على نجاحه. زر «اختبار الاتصال وجلب الأدوات» يستدعي شاشة OpenMinis الأصلية التي تنفذ handshake وtools/list فعلياً.
- اتصال العامل السحابي مستقل، ولا تُنقل إليه اعتمادات الجهاز تلقائياً.

## المهارات

حُزمت 59 مهارة من `openai/plugins` بالإصدار `0722921d5542fc593105c27bd52630babd8b8c2a`، مع المراجع والسكربتات الأصلية وتراخيصها، بمجموع ملفات يقارب 3.1 MB قبل الضغط. manifest يحدد المصدر والإصدار لكل مهارة. المجالات: iOS وmacOS وAndroid والويب والاختبارات والأمن وواجهات OpenAI وCloudflare وVercel والبيانات والتقارير.

تثبت محلياً مرة واحدة عبر SkillStore الأصلي. اسم المهارة المتكرر بين إضافتين يحصل على بادئة الإضافة في النسخة المثبتة فقط؛ الملفات المصدرية المحزومة تبقى أصلية. تعديل المستخدم وتعطيله وحذفه لا تُلغى عند إعادة التشغيل. العامل السحابي يثبت نفس المهارات عند تشغيله. أدوات ومتطلبات المهارة، مثل Xcode وChromium أو اعتماد الخدمة، يجب توفرها فعلياً؛ وجود النص لا يوفر تلك الأدوات وحده.

## المحرك والأسلوب

تعليمات الوكيل المحلي وCodex تتطلب تنفيذ المهمة والاستمرار بعد رسائل مستجدات قصيرة عند النتائج المهمة. كلام المستجدات منفصل عن function calling المنظم؛ نص JSON أو كود معروض داخل رسالة لا يتحول إلى أمر قابل للتنفيذ. اختبارات البث تغطي تداخل الكلام مع أجزاء معاملات الأداة وعدم تشغيل أمثلة JSON النصية.

يدعم خادم Codex حساب OpenAI أو مزوداً مخصصاً يدعم Responses API. توافق Chat Completions وحده لا يكفي لهذا المسار. المفتاح المخصص مشفر خارج config.toml، وتغيير المزود ممنوع أثناء وجود مهام نشطة. المحادثة المحلية تحتفظ بجميع مزودي OpenMinis الأصليين.

محرك Codex CLI الكامل لم يُحزم كبرنامج iOS. نسخة Linux تحتاج إلى تشغيل داخل محاكي نظام واستيفاء توافق العمليات والخيوط والمكتبات، ولم يثبت تشغيلها محلياً على الجهاز. مصادقة Codex واستخدام نماذجه داخل OpenMinis متاحة أصلاً، لكنها لا تعني وجود CLI محلي بكامل بيئته. قيود إيقاف iOS للتطبيق تظل قائمة.

## التجربة السحابية

بيئة Vercel التجريبية في حساب K داخل مشروع `cookies-app-work`، مع sandbox مستقل للمشروع. لها مهلة تشغيل محدودة وعنوان خاص بالجلسة. لا توجد اعتمادات مستخدم افتراضية داخلها، ولم يُختبر نموذج حي مدفوع دون ربط المستخدم لحسابه. لا تُحفظ رموز الوصول في Git.
