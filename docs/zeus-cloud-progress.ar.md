# حالة إصدار الحساب والتشغيل السحابي — 26 أكتوبر 2026

العمل على PR #6 في فرع feature/zeus-cloud-account-20261026، وما زال مسودة قيد التحقق.

## المنفذ

- مشروع Supabase مجاني، تسجيل بريد وكلمة مرور، تخزين جلسة الدخول في Keychain، فصل ملكية بيانات التثبيت ومنع إسنادها لحساب آخر.
- بروفايلات المتصفح وسجلاته وإعداداته بنسخ ذات تجزئة SHA-256، وعمليات حفظ ترفض التعارض بين الأجهزة.
- قاعدة مهام دائمة في Supabase مع RLS، وصلاحيات تنفيذ محددة خلف بوابة Edge، دون مفتاح إداري في التطبيق أو Railway.
- تشفير أسرار الحساب بمفتاح خاص بالمستخدم في Supabase؛ ملفات الوكيل مشفرة AES-GCM قبل تخزينها.
- إعادة استخدام النسخ الأصلي OpenMinis للمحادثات والمزودين وMCP والإعدادات، مع طبقة ملفات تشمل الملفات المخفية. الملفات الكبيرة مجزأة، والملفات غير المتغيرة يعاد استخدام مراجعها.
- خادم Python صغير بلا Chromium أو Codex أو نماذج محلية: حلقة الوكيل وPTY حقيقي، مهمة واحدة، طابور، موافقات محفوظة، إعادة اتصال، وعدم إعادة تنفيذ أوامر مجهولة النتيجة بعد إعادة التشغيل.
- واجهة اختيار محلي/سحابي، واجهة ملفات تطلب الملف عند فتحه، وطرفية سحابية ذات مدة محدودة. المحلي محفوظ كخيار.
- خدمة Railway الرابعة محدودة إلى 0.25 CPU و500 MB، وخيار النوم مفعل. النشر الفعلي والتحقق من النوم قيد الإنجاز.

## الأدلة الحالية

13 اختبار Python اجتاز: تنفيذ مستقل عن العميل، تشفير ونقل ملف مخفي، الطرفية الفعلية وحفظ ملفاتها، حدود الطلبات، منع تسريب الأسرار، الموافقات والملكية والتجزئة ومسارات الملفات. اختبارات دمج المحولات الأصلية اجتازت محليًا. بوابة Supabase المنشورة ACTIVE واجتازت اختبارات العزل والموافقات في قاعدة البيانات الحقيقية. بناء iOS لهذه الإضافة الجديدة لم يكتمل بعد.

بناء النسخة التأسيسية 4.0.0 (32) نجح، لكن اختبارات المحاكي أظهرت خطأ في تجهيز fixture للكشك ضمن اختبار الاستعادة (أُصلح في 33) وأربع حالات Files UI ما زالت تحتاج فحصًا. لا تمثل النسخة 32 هذه الميزات كاملة.

## ما لم يكتمل والتحفظات الفعلية

- إنشاء مستخدم Atlas رُفض مرتين من الأداة رغم تأكيد المستخدم. لا توجد بيانات اتصال Atlas؛ المخزن الفعلي للمهام حاليًا Supabase Postgres. محول Atlas جاهز فقط.
- Google مؤجل بطلب المستخدم. إعداد رابط التأكيد/استرجاع كلمة المرور وSMTP لدى Supabase يحتاج تحققًا خارجيًا؛ لا توفر الأدوات المتصلة تغيير إعدادات Auth.
- بروتوكولات الخادم الحالية OpenAI Chat Completions وAnthropic وGemini عبر واجهته الرسمية المتوافقة. OAuth وResponses وMCP وأدوات الجهاز السحابية لم تكتمل. لا يُستبدل مزود المستخدم بصمت.
- الموقع وحالة WebKit وبعض جلسات المواقع لا تضمن استعادتها بمجرد نسخ cookies. التخزين الخاص بالتصفح الخاص مستثنى. روابط المجلدات الخارجية تحتاج إذن iOS جديدًا بعد إعادة التثبيت.
- تنظيف ملفات جلسات الوكيل مشروط بنجاح النسخة المشفرة واستيرادها في الخادم ومطابقة تجزئتها. لا يُحذف rootfs أو بيانات أصلية غير مغطاة.
- ضغط/أرشفة السجلات الطويلة وحدود الحصة وتنظيف الأجسام غير المشار إليها قيد الإنجاز؛ لا يوجد وعد بتكلفة ثابتة أو بحفظ غير محدود.
- لم يُختبر نموذج تجاري فعلي ولا تسجيل بريد حقيقي من جهاز المستخدم، ولم تُنقل بيانات جهاز المستخدم أو تُحذف بعد.
